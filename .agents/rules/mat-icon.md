# Angular Material `mat-icon` Styling Rule

- Do NOT override `width`, `height`, or `font-size` on `<mat-icon>` elements (e.g., avoid Tailwind size classes like `text-lg`, `!text-lg`, `w-*`, `h-*`, or inline `font-size`/`width`/`height` styles).
- Let Angular Material's default `mat-icon` sizing apply.
